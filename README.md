# Arch Environment Configuration

Configuration and machine-state information used to recreate my Arch Linux environment.

## Contents

- `dotfiles/` — canonical user configuration managed with GNU Stow
- `packages/` — installed package manifests
- `state/` — generated machine and software state
- `system/` — selected system configuration
- `scripts/` — environment maintenance and bootstrap tools
